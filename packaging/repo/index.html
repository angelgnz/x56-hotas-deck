Ubuntu / Debian / Mint / Pop!_OS

APT

Add the signed APT repository and install with automatic future updates:

curl -fsSL https://angelgnz.github.io/packages/gpg.key | sudo gpg --dearmor -o /usr/share/keyrings/angelgnz-packages.gpg
echo "deb [arch=amd64 signed-by=/usr/share/keyrings/angelgnz-packages.gpg] https://angelgnz.github.io/packages/apt stable main" | sudo tee /etc/apt/sources.list.d/angelgnz-packages.list
sudo apt update && sudo apt install nxctl

Fedora Workstation

DNF

Enable the RPM repository with GPG verification:

sudo curl -fsSL https://angelgnz.github.io/packages/rpm/angelgnz-packages.repo -o /etc/yum.repos.d/angelgnz-packages.repo
sudo dnf install nxctl

Fedora Atomic / Silverblue / Kinoite / Bazzite

rpm-ostree

Add the repository under /etc/yum.repos.d and layer the signed RPM package cleanly:

sudo curl -fsSL https://angelgnz.github.io/packages/rpm/angelgnz-packages.repo -o /etc/yum.repos.d/angelgnz-packages.repo
rpm-ostree install nxctl
sudo rpm-ostree apply-live --allow-replacement
sudo udevadm control --reload-rules && sudo udevadm trigger -s hwmon
systemctl --user enable --now nxctld

openSUSE Tumbleweed / Leap & Aeon / MicroOS

Zypper

Import the GPG key and add the signed repository:

sudo rpm --import https://angelgnz.github.io/packages/gpg.key
sudo zypper ar -f https://angelgnz.github.io/packages/rpm angelgnz-packages
sudo zypper refresh && sudo zypper in nxctl
# On Aeon / MicroOS (immutable):
# sudo transactional-update pkg install nxctl

Arch Linux / EndeavourOS / CachyOS

Pacman

Trust the signing key, add the [angelgnz] repository block to /etc/pacman.conf, and install:

curl -fsSL https://angelgnz.github.io/packages/gpg.key | sudo pacman-key --add -
sudo pacman-key --lsign-key 4663D045FAB8BFB786EFCDE1246A5814FD9D8BB8
grep -qxF '[angelgnz]' /etc/pacman.conf || printf '\n[angelgnz]\nSigLevel = Required DatabaseOptional\nServer = https://angelgnz.github.io/packages/arch/$arch\n' | sudo tee -a /etc/pacman.conf
sudo pacman -Syu nxctl

Universal Linux (x86_64 Tarball)

Tarball

Download and install the standalone binaries, udev rules, and desktop entry on any Linux distribution:

TAG=$(curl -fsSL https://api.github.com/repos/angelgnz/x56-hotas-deck/releases/latest | grep -o '"tag_name": "[^"]*"' | cut -d'"' -f4)
curl -fsSL "https://github.com/angelgnz/x56-hotas-deck/releases/download/${TAG}/x56-hotas-deck-${TAG}-x86_64.tar.gz" | tar -xz
cd "x56-hotas-deck-${TAG}-x86_64" && sudo ./install.sh
